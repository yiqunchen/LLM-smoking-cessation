# LLM Smoking Cessation Project

This repository contains analysis scripts and data for evaluating LLM-generated smoking cessation messages.

## Project Structure

- `analysis-script/` - Python scripts for data analysis and evaluation
- `data/` - Raw and processed data files
  - `Messaging_Testing_Data.xlsx` - Original dataset
  - `R01 Message Summary for message testing paper.xlsx` - Message summaries with image mappings
  - `processed_llm_data.json` - Processed LLM responses (generated by preprocessing)
  - `downloaded_smoke_images/` - Image files used in the study

## Key Files

- `checkpoint_results_gpt-4o-mini_vision.json` - Evaluation results from GPT-4o-mini vision model
- `analysis-script/preprocess_data.py` - Data preprocessing script (run first)
- `analysis-script/main_eval.py` - Main evaluation script
- `analysis-script/plot_results.py` - Visualization scripts

## Setup and Usage

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Set OpenAI API key:**
   ```bash
   export CHEN_OPENAI_API_KEY="your-api-key-here"
   ```

3. **Preprocess the data (run first):**
   ```bash
   python analysis-script/preprocess_data.py
   ```

4. **Run evaluation:**
   ```bash
   # For vision mode (includes images)
   python analysis-script/main_eval.py --mode vision --model gpt-4o-mini
   
   # For text-only mode
   python analysis-script/main_eval.py --mode text-only --model gpt-4o-mini
   ```

5. **Generate plots and metrics:**
   ```bash
   python analysis-script/plot_results.py checkpoint_results_gpt-4o-mini_vision.json
   ```

## Data

The project evaluates LLM-generated smoking cessation messages against ground truth ratings for content quality, design, coping effectiveness, and quitting motivation. The preprocessing step converts the original Excel data into a structured JSON format that includes participant metadata and image mappings.
